# Arène des Algos

Objectif : monter un pipeline de Machine Learning (ML) sur un ou plusieurs dataset(s) existant(s) pour comparer plusieurs algorithmes et effectuer un classement

### Pré-requis

1. Créer un environnement virtuel : `python -m venv arene_algos_venv` puis l'activer : `.\arene_algos_venv\Scripts\Activate.ps1`ou commande similaire selon votre terminal/OS
2. Installer les librairies nécessaires : `pip install -r requirements.txt`
3. Ouvrir Jupyter local : `jupyter lab`

### Structure repo

1 dossier par jour avec les fichiers nécessaires et un README
- J1 : Pipeline Machine Learning
- J2 : Data Collect & Preprocessing
- J3 : Arène des Algos + Fight IA
- J4 : Introduction au Deep Learning, évaluation et choix métriques selon coûts métiers
